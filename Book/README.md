This directory contains the code referenced in the book.

We explore the use of unlicensed radio frequencies, LoRaP2P, for remote sensing and control. Proofs-of-concept simplify connection with sensors and actuators, and streamline message-passing through a network. As a key component of such applications as precision agriculture and other remote applications, these concepts avoid third-party services which may not be practical, reliable, or affordable, without inhibiting their use. The result offers a means for developers to proceed with common components and open-source software. We begin by setting the stage for an exploration of various features and functionality. Parts lists, wiring diagrams, and software are suggested throughout. The resulting proofs-of-concept have not been tested in an industrial environment but offer a start on developing prototypes.
